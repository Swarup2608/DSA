Think of this folder as a semester-one lecture series, minus the boring parts.

## 🧭 How to use these notes

1. Read top to bottom — each file assumes you know the ones before it.
2. Type out every code example yourself. Don't copy-paste. Your fingers need to learn the syntax as much as your brain does.
3. Do the "Try This" exercise at the end of each file before moving on.
